# 跨海通道开通后的渔港经营成效评估

业务资料均为合成记录。表头字段及跨表引用见 `fixtures/format.json`。

## 数据说明

周号按各地合作社同一季历。交易 type/buyer 对应本地货权：wholesale 是入手后再售，visitor 为最终购买；同货批、同经营者、等额的 dock 和 online 编号可为同一成交的渠道再报；未能唯一解释的记录列待核。迁转核实日期以 verified_week 为准，当前村归属以有效周为准。operator-open 补充缺报和停业状态，省略并不代表失业。
对照港分流排除比率为经新桥访问数除以观测流量，门槛为 fund 中比例。扶持申请按同一失收期和家庭计，同户的已发款先占名额。新候选优先登记有凭据的正损失，高损失优先，等损失时按申请标识稳定排序，超出家庭或基金余额的部分候审。

CSV 使用 UTF-8、逗号分隔，无引号与内嵌换行。未提供的字段是空字符串，作为关系值的 `-` 表示不适用。多值字段用竖线分隔，数值和日期单位见业务约定。

## 资料检查

使用 Node.js 22.23.4，依赖仅为 Node.js 标准库。运行 `npm ci --ignore-scripts --offline` 准备工作区。

运行 `npm run check:materials` 检查合成交接资料的字段与记录引用。运行 `npm test` 检查交接资料的读取和校验。
